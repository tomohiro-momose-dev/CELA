# 課題：BL-224 最小ドライラン用の仮想タスク

茅野市の自動運転バス導入を想定し、以下の小さな計画を作成してください。

## 与条件
- 予算上限（CapEx）：1,000万円
- 車両単価：250万円/台
- 充電インフラ：車両1台あたり50万円（予算から充当）

## 指示
1. 予算上限から「車両台数」を導出し決定すること。導出過程を reason_why に記載せよ（web_search は不要）。
2. 各車両に充電インフラ費（50万円）が必要なことを踏まえ再計算し、初期案が予算を超える場合は台数を修正（supersede）し、なぜ修正したかを明記すること。
3. 最終案について、それが依存する前提（予算上限・車両単価・充電インフラ費）を depends_on で明示すること。

※ このタスクは BL-224 の系譜グラフ（relation_edges）が実際に書かれ、監査で辿れることを確認する最小シナリオです。
